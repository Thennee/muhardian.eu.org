Google Apps Script (`Code.gs`)

Salin kode ini ke Google Sheets -> Extensions -> Apps Script

Cara Menjalankan setupSheet():

  1. Buka Spreadsheet Google Anda, klik menu Ekstensi (Extensions) > Apps Script.
  2. Hapus isi default, lalu tempelkan (paste) kode di bawah ini.
  3. Pilih fungsi setupSheet di bagian atas dan klik Run (Jalankan).
  4. Klik Deploy > New Deployment > Web App (Execute as: Me, Who has access: Anyone).
  5. Salin Web App URL lalu tempelkan di Pengaturan URL Script portal ini.
